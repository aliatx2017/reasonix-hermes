### Invocation

- CLI: `/skill-name` or `/skill-name arguments`
- Desktop: Settings → Skills browser
- Programmatic: `run_skill({name: "skill-name", arguments: "..."})`
- Subagent skills (tagged `[🧬 subagent]`) spawn isolated agent loops — use the dedicated top-level tool when available

### Skill Types

| Type | Behavior |
|------|----------|
| **inline** | Body folds into the parent turn — agent reads and acts on it directly |
| **subagent** | Spawns an isolated child loop returning only its final answer — use for context-heavy work |

### Adding Skills

```bash
# Install from URL
reasonix install-source install --source https://github.com/user/skills --kind skill

# Install from local folder
reasonix install-source install --source ./my-skill-folder --kind skill

# Author inline
install_skill({name: "my-skill", description: "...", body: "..."})

# Author subagent
install_skill({name: "my-skill", description: "...", body: "...", runAs: "subagent"})
```
