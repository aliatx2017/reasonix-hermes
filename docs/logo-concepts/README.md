# Reasonix-Hermes Logo Concepts

7 design directions blending:
- **Reasonix** — concentric diamond ◈, rainbow gradient, terminal aesthetic
- **Hermes Agent** — winged helmet, geometric angular, tech-greek fusion
- **DeepSeek** — whale arc, ocean gradient, upward motion

Open `index.html` in a browser to preview all 7 concepts with specs, palettes,
and recommendations.

## Unified Palette
| Color | Hex | Role |
|-------|-----|------|
| Cyan | `#06b6d4` | Primary / start of gradient |
| Indigo | `#6366f1` | Midpoint |
| Violet | `#8b5cf6` | Accent |
| Fuchsia | `#d946ef` | End of gradient / highlight |
| Near-black | `#080810` | Background always |

## The 7 Concepts

1. **Diamond Wing** — Reasonix diamond core + Hermes swept wings ⭐ **[animated version →](01-diamond-wing-animated.svg)**
2. **Whale-Wing** — DeepSeek whale arc + Hermes wing + diamond heart
3. **Terminal Talaria** — Winged sandals as blinking cursor
4. **Monospace "RH"** — Pure typographic mark, monospace wordmark
5. **Caduceus Circuit** — Staff + serpent traces reimagined as PCB
6. **Helmet Forward** — Face-on Greek helm, diamond third eye
7. **The Navigator** — Whale diving through diamond constellation
