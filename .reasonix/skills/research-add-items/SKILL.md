# Research Skill — Add Items

## Trigger
`/research-add-items`

## Workflow

### Step 1: Locate Existing Outline
Find and read `outline.yaml` in the current working directory or workspace root.

### Step 2: Search with SearXNG for More Items
Ask the user: "What area should I search for additional items?" or use the topic from `outline.yaml`.

Use **the local SearXNG instance** for structured multi-engine search:

```bash
curl -s 'http://192.168.1.214:30053/search?q=<URL-ENCODED-QUERY>&format=json'
```

Search with different angles to discover items the initial outline might have missed:
- Competitors, alternatives, or adjacent players
- Sub-categories or sub-fields within the topic
- Recent entrants (use `time_range=year`)

Parse the JSON results to identify new items, their URLs, and brief descriptions.

If SearXNG is unreachable, fall back to web_fetch with Wikipedia or HN Algolia search.

### Step 3: Supplement
Ask the user to confirm the new items, then update `outline.yaml` by appending new entries under `items:`.

### Step 4: Confirm
Show the updated items list to the user.
