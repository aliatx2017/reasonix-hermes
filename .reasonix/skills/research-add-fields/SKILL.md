# Research Skill — Add Fields

## Trigger
`/research-add-fields`

## Workflow

### Step 1: Locate Existing Fields
Find and read `fields.yaml` in the current working directory or workspace root.

### Step 2: Suggest Additional Field Dimensions
Based on the research topic and existing fields, suggest additional field dimensions that would be useful for comparison:
- What other attributes would help differentiate the items?
- Are there metrics, dates, or qualitative dimensions missing?

Use **SearXNG** to discover what fields are commonly used in similar research:

```bash
curl -s 'http://192.168.1.214:30053/search?q=<topic>+comparison+criteria+analysis&format=json&categories=science'
```

Optionally use **crawl4ai** to deep-read any comparison or survey articles found:

```bash
curl -s -X POST http://192.168.1.214:11235/crawl \
  -H 'Content-Type: application/json' \
  -d '{"urls": ["<url>"], "priority": 10, "extract_markdown": true}'
```

### Step 3: Update
Ask the user to confirm the new fields, then update `fields.yaml` by adding new entries under `fields:`.

### Step 4: Confirm
Show the updated field definitions to the user.
